# 🌍 Country Info Finder

A responsive React app to search and view country information using the [REST Countries API](https://restcountries.com). Built with React, React Router, and Bootstrap. Includes loading states, animations, and error handling.

---

## 🚀 Features

- 🔍 Search for any country by name
- 📄 View country details:
  - Official Name
  - Capital
  - Population
  - Region
  - Currency Symbol
  - Flag
  - Area
  - Continents
  - Borders
  - Independent status
- 🔄 Loading spinner while fetching data
- ❌ Error message for invalid country or empty input
- ✅ Reusable CountryCard component
- 📱 Fully responsive on mobile, tablet, and desktop
- 🎨 Smooth fade-in animation

---

## 🛠️ Tech Stack

- React
- React Router DOM
- Bootstrap 5
- REST Countries API

---

## 📦 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/react-country-info-finder.git
cd react-country-info-finder
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.
